## 🌟 Overview

**NEXDROID** is a cutting-edge, military-grade cyberpunk mobile application built on Flutter & Dart. It unifies high-frequency social messaging, decentralized offline mesh networking, real-time threat intelligence, cyber diagnostics, high-performance media processing, a custom 3D gaming engine, and an interactive command deck.

## 🚀 Flagship Cyber Tools & Modules

### 1. 🎵 Holographic Music Player (`/music-player`)
- **Holographic 3D Gyro-Turntable:** Custom `_CyberTurntablePainter` with dynamic rotational physics and holo telemetry rings.
- **36-Bar Spectrum Visualizer:** Real-time multi-frequency audio visualizer bars.
- **DSP Equalizer Matrix:** 6 studio-engineered presets (`STUDIO FLAT`, `BASS BOOST`, `CYBER SYNTH`, `SPATIAL 3D`, `VOCAL MATRIX`, `ELECTRO-PULSE`).
- **Time Warp Slider:** Dynamic variable-rate playback (0.5x – 2.0x).

- **Hardware MFLOPS Benchmark:** High-precision compute rating engine.

## 📦 How to Build the APK (Step-by-Step)

### Step 1: Clone the Repository
```bash
git clone https://github.com/nexchat23-dev-team/NEXDROID.git
cd NEXDROID
```

### Step 2: Accept Android Licenses (First Time Only)
```bash
flutter doctor --android-licenses
```
*(Press `y` to accept all SDK licenses if prompted)*

### Step 3: Install Flutter Dependencies
```bash
flutter pub get
```

### Step 4: Build the APK

#### Option A: Debug APK (Fastest, for testing)
```bash
flutter build apk --debug
```
> **Output APK:**  
> `build/app/outputs/flutter-apk/app-debug.apk`

#### Option B: Release APK (Optimized production build)
```bash
flutter build apk --release
```
> **Output APK:**  
> `build/app/outputs/flutter-apk/app-release.apk`

#### Option C: Split Per-ABI APKs (Smaller file size per architecture)
```bash
flutter build apk --split-per-abi --release
```
> **Output APKs:**  
> - `build/app/outputs/flutter-apk/app-armeabi-v7a-release.apk` (Older 32-bit devices)  
> - `build/app/outputs/flutter-apk/app-arm64-v8a-release.apk` (Modern 64-bit devices, recommended)  
> - `build/app/outputs/flutter-apk/app-x86_64-release.apk` (Emulators / Chromebooks)

## 📱 How to Install the APK on Your Android Device

### Method 1: Via ADB (USB Debugging)
1. Connect your phone via USB with **USB Debugging** enabled in Developer Options.
2. Run:
   ```bash
   adb install -r build/app/outputs/flutter-apk/app-release.apk
   ```

### Method 2: Direct File Transfer
1. Copy `app-release.apk` (or `app-debug.apk`) to your phone (via Google Drive, WhatsApp, Telegram, or USB).
2. Open the file on your device and tap **Install** (allow "Install from Unknown Sources" if prompted).

## 🔧 Troubleshooting

| Issue | Resolution |
|---|---|
| `Some Android licenses not accepted` | Run `flutter doctor --android-licenses` and press `y` for all prompts. |
| `Java version mismatch / compile error` | Ensure `JAVA_HOME` points to **JDK 17** (`java -version`). Gradle 8+ requires Java 17. |
| `Desugaring failed` | Android Gradle Plugin requires `coreLibraryDesugaring` which is already configured in `app/build.gradle.kts`. Run `flutter clean && flutter pub get`. |
| `Camera / ML Kit permission denied` | Ensure you accept camera permissions on first launch. Permissions are configured in `AndroidManifest.xml`. |
